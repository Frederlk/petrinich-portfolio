## Patterns and decisions

- The site has no CMS and no database. It is statically rendered, and the copy of each section lives in a constants module next to that section.
- The contact form posts from the browser to Web3Forms, and a Zod schema validates it for the visitor. A failed send does not start the 5 second cooldown.
- Env variables go through T3 Env, and skipping env validation is refused in production.
- Security headers, HSTS, AVIF and WebP images and the redirects live in the Next.js config.
- Blur placeholders for the raster images are generated by a script that runs before dev and before build.
- A second script fails CI on dead public paths, on SVGs loaded through an image source attribute and on comments over the budget.
- The pnpm workspace sets a three-day release cooldown for new packages.

## Cases

**A page that is right before JavaScript arrives.** The hero entrance was a GSAP from tween, which runs after the first paint. The hero showed, then snapped to hidden. My first fix in the global stylesheet still left the heading fully visible for 3.58 seconds under a 400 kbps throttle. I moved the hidden state into an inline style block that ships in the same bytes as the elements, switched on by a server-rendered attribute. A CSS animation ends it after 1.5 seconds, so a broken bundle cannot leave the hero blank. A noscript rule shows everything when JavaScript is off. The diagram sections go the other way: the server renders them visible, and GSAP writes the hidden state in an effect. The Skip control of the intro is plain CSS too, and an inline listener keeps its tick through hydration.

**An intro film for every browser engine.** The site opens with a 55 second film in a full-screen overlay. WebKit picks a WebM it cannot play from a file-based video element and hangs. iOS reads the muted attribute, not the property. On a 1.5 Mbps link hydration ended at 11.4 seconds and the film began at 12.2. I listed MP4 and WebM sources with the narrow-viewport encodes first, chosen by media query before any script runs. I removed WebM on WebKit by checking the browser vendor and set muted through a ref callback. A loading label and the Skip control are in the server HTML. The ambient wash behind the content needed its own video. A second element on the feature file doubled the decode and dropped 39 percent of frames. A separate 160 by 106 encode dropped 0.23 percent.

**What changed between 2025 and 2026.** The first version, in April 2025, was a conventional marketing page. It had seven lazy-loaded sections with three more hidden by comment, AOS, Embla Carousel carousels, a footer subscribe form and a contact form. In September 2026 I rebuilt it as one cinematic landing of 16 sections with GSAP and smooth scroll, plus the intro film. The contact path is now a single "Request an introduction" modal, and all direct contact routes are gone. The rebuild added analytics with an opt-out toggle on the privacy page. ESLint and Prettier gave way to Biome with Ultracite in June 2026, and the rebuild added the pointer check, the security headers and the release cooldown.
